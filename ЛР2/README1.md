# Анализатор метрики Джилба для JavaScript

Программа-парсер с графическим интерфейсом (Tkinter). Рассчитывает по исходному
коду на JavaScript абсолютную сложность CL, относительную сложность cl и
максимальный уровень вложенности CLI.

## Файлы

- `gilb_gui.py` — графический интерфейс, основной запускаемый файл.
- `gilb_core.py` — токенизатор JavaScript и расчёт метрики.
- `example.js` — анализируемая программа; загружается при запуске автоматически.

## Запуск

```bash
python3 gilb_gui.py
```

Нужен только стандартный Python 3 (на Linux может понадобиться `sudo apt install python3-tk`).

## Правила подсчёта

**CL — количество ветвлений.** Учитываются:

| Конструкция | Вклад в CL |
|---|---|
| `if`, каждое `else if` | 1 |
| `for`, `for..in`, `for..of`, `for await..of` | 1 |
| `while`, `do..while` | 1 |
| тернарный оператор `?:` | 1 |
| `switch` | число ветвей `case` |

Оператор `switch` заменяется вложенными операторами условия: каждая ветвь `case`
даёт один `if`, вложенный в `else` предыдущей ветви. Селектор `switch (x)` и ветвь
`default` условиями не являются. Несколько меток с общим телом
(`case 9: case 10:`) образуют одну ветвь — одно условие `x == 9 || x == 10`.

**cl = CL / N**, где N — общее количество операторов программы:
объявления `var`/`let`/`const`, операторы-выражения (присваивание, вызов функции,
`++`), `return`, `throw`, `break`, `continue`, `try`, операторы ветвления и циклов.
Не учитываются: объявления функций и классов, пустой оператор `;`, блок `{ }`,
`import`. Каждая ветвь `case` считается одним оператором `if`; `break`,
завершающий ветвь `case`, не учитывается (в эквивалентной записи через `if`
его нет).

**CLI — максимальный уровень вложенности ветвлений** (включая циклы).
Внешнее ветвление имеет уровень 0 — так же, как в методичке: оператор выбора
с n ветвями эквивалентен n − 1 оператору `if` с глубиной вложенности n − 2.
`else if` вложен в `else`, поэтому увеличивает уровень на 1.
Флажок в окне переключает отсчёт с 1.

## Проверка на примерах методички

Рис. 3 (цепочка `if`) и рис. 2 (`switch` с пятью ветвями), переписанные на JS:
CL = 4, N = 11, cl = 0,36, CLI = 3 — совпадает с методичкой.

## Результат для `example.js`

CL = 13, N = 37, cl = 13 / 37 ≈ 0,351, CLI = 4.

Самая глубокая вложенность: `for..of` (0) → `if` (1) → `else` → `for` (2) → `if` (3) → `else if` (4).

## Ограничения

- Регулярные выражения распознаются по предыдущему токену (эвристика).
- Логические `&&`, `||`, `??` ветвлениями не считаются: метрика Джилба учитывает
  операторы, а не составные условия.
